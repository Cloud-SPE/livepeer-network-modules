Suspended members

Suspension drains a member's placements: in-flight requests finish where they are, and no new work is routed. Reinstating puts the member back to active — placement will offer the GPUs work again on the next apply.

Active members

A suspension with no reason is a decision nobody can review later, including the operator who made it — so the reason is required here, not only at the server.

Suspended hardware

GPUs the pool has stopped sending work to. Hardware state is set by certification and the ladder, not from this page.

Held settlement windows

Anything anomalous, and anything sitting in pending_approval. The settlement scale is what the window actually collected against what it billed: below 1 000 000 ppm the pool would be paying out more than it took in.

Duplicate GPUs

The same GPU UUID claimed by more than one member address. Listed rather than resolved: the pool can tell that two addresses claim the card, not which one is entitled to it.
