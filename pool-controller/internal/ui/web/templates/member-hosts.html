Reading a placement

State Where the placement sits on the ladder: pending, testing, probationary, active, throttled, draining, suspended, retired.
Reason The code for the last transition. It is the pool's answer to "why is it here", recorded when the transition was made.
Evidence The measurement behind the reason — the failure, the score, the count. This is what you would have to change.
