Your choices

Settings

Three things are yours to decide: which workloads you decline, when a host credential is replaced, and when a host leaves the pool. Each is confirmed before it takes effect.

Declined templates

You may refuse a template and placement will honour it. You cannot request one: which GPU runs which workload is the pool's policy, not a queue you can join. A refusal with no GPU named covers every GPU on your address.

Decline a template

The list suggests templates currently placed on your own GPUs. Any template ID the pool's catalog carries is accepted; one it does not is rejected rather than stored.

Host credentials

Rotating issues a new enrollment token and revokes the old one immediately. The running agent will stop being able to attach until it is given the new token, so rotate when you can restart the host.

Retire a host

Retiring is your own exit. Placements are set to drain, not stopped: work already dispatched finishes where it was sent, and the host goes quiet once it has. It is not instant and it is not a kill switch.

This browser

Host credentials are kept in this browser so the portal can read your hosts' status; the controller keeps only a hash of them and cannot hand one back. Clearing them here does not affect a running host — it only stops this browser from showing it.
