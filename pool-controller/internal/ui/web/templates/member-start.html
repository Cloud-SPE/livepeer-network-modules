Get started

Add a host

Enrolling a host gives you a credential and a bundle. You unzip it and run one command; from there the pool assigns templates, the agent starts the runners, and certification happens on its own. There is no operator step on this path.

1 · Name the host

A label only you see. Use something you will recognise on the Hosts page — the machine's hostname is usually enough.

2 · Save the credential

3 · Download the bundle and run one command

What happens after the command

Attach The agent connects outbound with its credential and reports the GPUs it can see. Nothing is opened on your network.
Placement The pool matches each GPU to the templates it qualifies for, and the agent pulls the runners for them.
Certification, then earning Each placement is certified, runs capped on probation, and is promoted automatically once it has proved itself.

Every one of those steps, and the reason it is where it is, shows on Hosts.

Already have a host?

This browser keeps the credentials of hosts you enrolled here so the portal can read their status. A host you enrolled in another browser is not listed until you add its credential back.

If the token is lost, rotate it from Settings on a browser that still has it, or ask the operator to revoke the host and enrol it again.
