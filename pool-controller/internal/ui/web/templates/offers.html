Workload catalog

Offers

The catalog lives in templates/ and is reviewed in version control, so an operator no longer authors offers. What a pool decides per template is small: whether to enable it, and what it charges. The offer set the brokers receive is derived from those two decisions.

Template catalog

A template sits in one of three states. Not adopted — no override exists and no offer is pushed for it. Disabled — the offer is still pushed so the broker keeps it, but it is not advertised. Enabled — advertised at the price shown. Saving a price on a template that was never adopted adopts and enables it.

Price and enablement are the only fields this panel writes. An extra metadata override is authored elsewhere and is carried through unchanged when you save from here.

Derived offer set

Read-only. The controller recomputes this from the adopted templates on every read using the same code the broker push runs, so it is exactly what the fleet was sent — there is no stored offer that could disagree, and nothing here is editable. To change an offer, change its template above.
